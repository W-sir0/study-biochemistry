# 推理核对

## 结构、蛋白质与酶

区分构型与构象、变性与肽键水解、协同性与别构效应。描述“结合更强”时明确比较的是解离常数、结合自由能还是实验读出。米氏参数的解释依赖反应机制和实验条件；不要把 Km 无条件等同于 Kd。酶降低活化自由能，不改变给定条件下的平衡常数。

## 遗传信息

核对链方向、模板链与编码链；合成方向与模板读取方向分别写明。区分细菌与真核生物的复制、转录、RNA 加工和翻译。比较突变和修复时追踪原始损伤、修复底物及最终结果；表观修饰的作用依赖位点和背景，避免统一解释为激活或沉默。

## 代谢与能量

先定义生物或组织、细胞区室和生理状态。平衡化学方程时核对碳、氮、磷、电子和电荷。区分 ΔG 与 ΔG°′、稳态与平衡、通量与代谢物浓度；NADH 与 NADPH 的主要用途不能任意互换。ATP 收支写出活化代价、底物水平磷酸化、还原当量、P/O 比、跨膜转运及穿梭条件；遇到旧式计数应先注明口径。

分解和合成通常不是同一套反应简单倒转。比较糖酵解与糖异生、脂肪酸氧化与合成时核对绕行步骤、酶、区室与辅因子。光合磷酸化与碳固定分开说明，再连接 ATP、NADPH 与碳收支。

## 实验与图表

先读图例、坐标、单位、对照、重复及误差定义，区分观测与机制推断。纯化、相互作用、结构测定和结构预测回答不同问题；模型置信度不能代替实验验证。不补造教材图中没有的数值、统计量或实验条件。
